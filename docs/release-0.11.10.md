# YoLink 0.11.10

## 修复

- 失败任务重试核对原规则快照；账号、源目录、输出映射已变更或历史任务缺少快照时拒绝旧任务重试，提示按当前规则重新生成。改名、通知等不改变映射的设置不影响重试。
- 全量、指定目录、预览、失败重试及旧断点恢复使用一致的目录名转换，保留原云端路径用于查询，不覆盖不同内容的已有文件。
- 入库队列在批次限制前按空闲规则选择最早事件，繁忙规则的大量待处理事件不再挡住其他规则。
- 规则编辑器保存栏跟随原版/玻璃主题；浅色文字使用深色透明底，增强对比度时采用实色降级，不再出现旧导航颜色造成的白条。

## 在线壁纸

在「皮肤管理 → 在线图片网址」粘贴 HTTPS 图片直链，点击「使用在线壁纸」。保留本地图片上传与现有模糊、遮罩、铺满/完整显示设置。

在线壁纸由浏览器直接访问图片站点，不经过 NAS 代理；不发送 Referer，仅在当前浏览器保存网址，刷新时重新加载。只放开 CSP 的 HTTPS 图片来源，脚本、样式及 fetch 仍限制在本站。加载失败/15秒超时保留原壁纸；刷新时远端不可用则回退默认背景，可以重试或清除。防盗链、需登录或非图片网页链接可能无法使用。

## 数据与验证边界

不迁移数据库结构，不删除媒体、STRM、凭据或规则。更新容器会使现有管理会话失效，请使用原密码重新登录。

本地 Go 测试、vet、构建，88 项前端单元测试和 34 项浏览器测试通过；新功能覆盖桌面/手机、错误/超时、存储失败、刷新恢复及主题降级。测试使用隔离数据，不代表真实网盘播放验证。部署与镜像推送结果分别记录。
