# 0.14.1 更新说明

本版本包含安全、恢复、启动与连接检查方面的修复，不改变数据库结构版本（仍为 schema 5）。

## 升级前

1. 先备份数据库、密钥、`.env`、Compose override 与输出目录。
2. 镜像默认改为 UID/GID `10001:10001` 运行。停止旧服务后，按 [快速开始](../QUICKSTART.md#升级与备份)处理已有目录、数据库和密钥的权限；NAS 也可在 `.env` 指定合适的 `YOLINK_UID`/`YOLINK_GID`，并通过 ACL 授予共享输出目录写权限。
3. 运行 `docker compose run --rm --no-deps yolink check-permissions`，通过后再启动。首次安装也需先创建挂载目录；Compose 不会自动创建 root 所有的宿主机目录。

## 管理员密码与接入凭据

- 新密码至少 10 个字符；已有初始密码仍可登录。
- 修改密码会撤销已有管理会话，并轮换兼容事件令牌。改密后请同步更新 Hermes 或旧脚本中的兼容凭据。独立接入应用的令牌不受此次轮换影响。
- 兼容事件令牌按需通过管理员接口读取，可在服务设置手动轮换，不再随常规状态响应返回。
- 修复 Windows 改密时“磁盘已保存但接口报失败”的问题；文件已发布后若目录同步失败，运行中的认证也会采用已发布的新凭据并明确提示。

## 生成、迁移与恢复

- 大量积压任务不再阻塞 HTTP 服务启动；重复入库事件不会拆开正在执行的任务。
- 迁移进度遇到未完成的尾记录时，先修复尾部再续写；支持继续迁移、重新加载及回滚，并保留中间损坏记录供排查。
- 大迁移预览限制原文保留量，超出部分在使用时重读并校验。
- 大备份的处理时限按体量调整；恢复状态查询可在导入/导出过程中使用；不支持 fallocate 的文件系统改用实际写入预留回滚空间。

## 连接与工程

- 连接检查只读取目录第一页；139 续期间隔受限；只读网盘查询对瞬时故障有限重试。
- 收紧联动和下载地址检查，补齐登录限速、前端状态竞态及 Hermes 配置查找的处理。
- 新增 Linux、Windows、Docker 权限和前端 CI。Docker 验证覆盖首次安装、旧 root 数据卷升级、自定义运行用户、重启与已有密钥/STRM 保留。

已有服务地址及播放签名密钥继续使用原值；输出文件的迁移、修复仍需按页面预览和确认流程执行。
