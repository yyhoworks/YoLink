# YoLink 0.12.0

第一批可靠性改进。加密备份恢复、增量同步、变更预览与受控修复、规则模板仍在后续版本计划中，本版不包含未完成的实现。

## 账号健康与恢复

- 分别显示目录、播放地址解析和容量检查的观察结果、时间、重试提示；未测试及不支持的能力不伪装为健康。
- 失败任务先按账号筛选再分页，明确显示恢复资格。用户选择任务并确认后才进入原任务队列；账号修订或规则变化后拒绝旧请求。
- 同一故障状态不反复发通知，取消检查不误报凭据失效。

## 播放诊断

- 从已登记媒体检查索引、本地 STRM、账号和解析结果，可选最多读取 1024 字节的有限取流。
- 可取消并导出脱敏报告；不接受任意目标 URL，不回显临时播放链接、凭据或完整路径，不覆盖用户修改的文件。
- NAS 侧有限取流成功不等于播放器解码、拖动或完整播放成功。

## 基础与刷新优化

- 账号级请求调度：播放请求可在扫描分页间优先执行，兼顾后台任务公平性；凭据更新和账号修订使用同一调度约束。
- 数据库升级为事务化版本迁移；紧凑断点将目录快照、游标与输出归属拆分保存，降低大目录的逐项写入开销。
- 活跃任务页约 4 秒刷新、空闲约 30 秒；隐藏页面暂停刷新，设置按需加载，保留输入草稿与焦点，异常退避最长 60 秒。
- 保持 Go + SQLite + 静态网页 + 单容器；不新增后台依赖，不更改默认端口与挂载规则。

## 升级与回退

保留整个数据目录、密钥、输出、环境配置与 Compose override。旧版升级会将 SQLite `user_version` 从 0 逐步迁移至 4；升级前必须停止旧容器并制作一致的数据备份。不要同时启动新旧程序。

若回退旧版，应停止新版，保留升级后数据副本，再恢复升级前的一致数据与匹配旧镜像；不要假设旧程序能够理解或撤销新数据库结构。生成文件不自动删除，用户修改内容继续保留。

## 验证范围与限制

候选代码具有 Go、前端单测、桌面/手机浏览器及真实 HTTP/SQLite 隔离端到端测试。发布还需匹配提交的独立审查、Linux 竞态检测、真实网盘兼容性、升级与群晖验收证据；以发布记录的实际结果为准。

强制终止回归覆盖文件发布后、输出归属/活动记录写入中、游标提交前的恢复，以及用户改写文件保护和生成数量限制。断点前已发布的同内容文件会在恢复时跳过；创建/跳过统计可能变化，活动记录可能重复。这不代表整次扫描是跨文件和数据库的原子事务，也不提供硬件断电保证。
