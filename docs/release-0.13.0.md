# YoLink 0.13.0

新增手动加密备份与应用数据恢复。沿用 Go、SQLite、静态网页和单容器，不新增后台服务。增量同步、变更核对与模板仍待后续版本实现。

服务设置页可使用独立口令导出 age 加密文件，包含一致的应用数据库、凭据/播放/事件密钥、管理员校验资料及应用管理的恢复副本。网盘媒体、外部输出目录、Compose 和环境配置须分别备份。

Linux 恢复先在私有候选目录完成解密、完整性、数据库版本与配置校验；确认后再重启替换应用数据，并保留恢复前基线。恢复后保持保护状态，历史任务、规则、事件和通知不会自动重放。完成核对后再次重启，按需逐项启用自动工作。手动回退先保留当前完整数据，再恢复本次原基线。

文件操作采用独占数据目录锁、持久日志、文件与目录同步、物理回退空间预留和外部临时资料所有权记录。中断后由启动流程清理未启用明文或回退，无法核对时拒绝启动，保留现场。Windows 管理页支持导出，恢复激活保持禁用。

操作需要当前管理员密码；替换、核对和重启须输入对应确认文字。上传校验成功不会自动启用；网络中断后先刷新状态，不自动重复写请求。校验摘要与恢复状态区分未确认候选、等待重启、已安装和待核对。

限制及回退命令见 [备份与恢复操作](backup-restore.md)。最多 10 万个文件和 10 万个父目录，单文件 2 GiB，总载荷 4 GiB；历史恢复最多 65 层。请为候选、原副本、临时写入和回退预留足够空间。

发布验证需核实固定提交、镜像、Linux 恢复演练、满盘与并发检查及实际群晖升级结果。进程故障与 tmpfs 测试不构成硬件断电或所有文件系统可靠性的保证。升级仍需停止旧版并单独保存一致备份，避免同时运行不支持数据目录锁的旧版程序。
