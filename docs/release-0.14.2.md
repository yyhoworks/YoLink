# 0.14.2 更新说明

本次更新调整工作台导航，并整理项目首页文档。数据库结构仍为 schema 5。

## 导航与文档

- 桌面导航将「服务设置」移到「更多」前面；键盘焦点顺序与显示顺序一致。
- 手机底栏的「更多」继续位于最右侧，服务设置仍可从中进入。
- README 增加 5 张使用合成数据的界面截图，整理功能、网盘通道、部署步骤、文档导航与常见问题。
- 统一程序、网页版本显示和静态资源缓存版本，更新后刷新页面即可加载新导航。

## 升级

镜像为 `yyhoworks/yolink:0.14.2`（Linux amd64），同时同步 `latest`。

沿用现有数据、密钥、输出挂载、运行用户和 Compose override。先备份，再按 [升级与备份](../QUICKSTART.md#升级与备份) 更新。

从旧的 root 运行版本升级时，仍需按照 0.14.1 的要求处理目录权限并运行 `check-permissions`；详见 [0.14.1 更新说明](release-0.14.1.md)。
