# YoLink 0.11.11

## 运行记录修复

- 播放汇总先用精简数值字段分组，再读取完整事件，避免大体积记录在多次窗口排序中耗尽容器的临时空间。保留现有分组、搜索、分页和请求详情，不删除历史记录。
- 切换播放、生成和通知记录时立即清空旧标签内容；请求失败显示明确的重试提示，刷新后可恢复，不再把通知记录留在播放标签里。
- 玻璃主题的错误提示使用匹配文字明暗的底色，修复白条与低对比度；手机端的加载、空列表和错误状态不再套用旧白色卡片。

## 数据与验证

不迁移数据库结构，不改变临时空间限制，不删除媒体、STRM、凭据或规则。更新容器后请使用原密码重新登录。

Go 全量测试、vet，88 项前端单元测试和 37 项浏览器测试通过。补充大体积播放事件、请求详情、桌面/手机标签切换及错误恢复回归测试；使用实际数据库的只读隔离诊断验证 32 MiB 临时空间下的汇总查询。未发起真实网盘扫描或媒体播放。
