# YoLink 0.14.0

- 增加持久扫描观测和按能力对比：继续完整列目录，减少重复生成和写盘；明确区分完整、局部、不完整范围及来源未见。
- 变更核对展示来源变化和本地问题。缺失 STRM 先预览，再确认精确范围；逐项保存意图、核对归属/哈希/父目录身份，保留并发出现或被修改的文件。
- 电影、剧集、音乐草稿模板及 Emby/Jellyfin 映射指引，保存为普通可编辑规则。
- schema 5 事务迁移、旧断点兼容、扫描/修复容量和保留策略、恢复后隔离旧基线及预览。

没有云端写入、自动来源删除、已有 STRM 更新或未经验证的网盘变更游标。具体边界和使用方法见 [增量同步说明](incremental-sync.md)。

验证与独立审查记录在私有交付台账。候选代码、镜像及群晖验收的一致性确认后方可标记交付完成。
