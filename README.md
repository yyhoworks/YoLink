# YoLink

面向 NAS 的网盘 STRM 生成与播放入口服务。直接接入移动云盘、夸克、阿里云盘和 115；Go + SQLite + 内嵌网页，单容器运行，默认端口 **8796**。

当前源码版本：**0.11.10**。本仓库作为邀请内测的私有源码仓库，仅受邀 GitHub 账号可以访问。软件许可证仍为 AGPL-3.0，详见下方许可说明。

## 主要功能

- 网盘凭据导入、连接检查、容量查询与文件浏览。
- 全量、指定目录、定时及入库事件触发 STRM 生成；支持预览、任务取消、断点恢复和失败重试。
- 稳定签名播放入口，播放时解析临时下载地址；按网盘通道提供 302，或在显式允许后进行服务器中转。
- 可选复制匹配字幕及常用媒体资料；相同内容跳过，保留不同内容的已有文件。
- 生成、播放、诊断和通知记录，媒体库刷新及 Webhook/Telegram 通知。
- 原版/玻璃外观、浏览器本地壁纸和 HTTPS 在线壁纸，支持桌面与手机布局。
- 已登记 STRM 缺失修复、播放入口维护及带备份的旧 STRM 迁移工具。

## Docker 启动

获得仓库访问权限后，在运行 Docker 的主机上执行：

```sh
git clone https://github.com/yyhoworks/YoLink.git
cd YoLink
docker compose up -d --build
```

此仓库默认使用 `Dockerfile` 从源码构建，不要求将预编译程序提交到 Git。首次构建需要访问 Go 模块与容器基础镜像源。私有镜像分发尚未在本仓库配置。

访问 `http://你的NAS-IP:8796`。首次随机管理员密码保存在项目数据目录的 `data/initial-admin-password.txt`。登录后依次添加网盘凭据、填写播放器可访问的服务地址、选择目录并配置生成规则。建议先预览或试生成少量文件。

默认挂载：

| 主机目录 | 容器目录 | 内容 |
| --- | --- | --- |
| `./data` | `/data` | 数据库、加密凭据和服务密钥 |
| `./strm-test` | `/strm` | 新生成的 STRM 与可选配套资料 |

升级时保留数据目录、密钥、输出目录、`.env` 与自定义 Compose override。具体安装与挂载方法见 [快速开始](QUICKSTART.md)。

## 使用边界

本项目只导入用户已有的网盘凭据，不提供扫码/短信登录、公共 OAuth 应用、转存、刮削或整部媒体下载。各网盘授权、权益和接口变化会影响可用性。

“已返回 302”或有限取流自检成功不等于播放器完成解码、拖动或全片播放；实际播放器需要单独验证。生成文件默认不覆盖不同内容，也不自动删除用户文件。
